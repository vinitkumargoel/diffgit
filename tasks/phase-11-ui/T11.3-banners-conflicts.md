# T11.3 — Operation banner, reflog panel, conflict card

**Size:** M · **Depends on:** T11.2, T10.2, T10.3 · Design §14.3, §14.5 (Reflog) · Atlas tabs 06, 07

## Deliverables
- `OperationBanner` in the WarningBanners stack from `RepoInfo.operation` (kept fresh by refresh):
  wording per kind, `step k of n`, `Show steps` popover (done ✓ / current ▶ / remaining), copyable
  `--continue`/`--abort` commands, warning level while `conflicts > 0`, info otherwise; a second info
  banner for detached HEAD during an operation. Never dismissible while the operation persists.
- Conflict card body (`ConflictBody.tsx`): three `DiffBody` columns (base→ours, base→theirs, plus the
  base column rendered as context-only), labels `Base · stage 1`, `Ours · <label>`, `Theirs · <label>`,
  3-column grid ≥ 900 px, stacked below; then the working-tree file with marker lines in
  `--purple-bg`/`--done` (token names from §3), then a `Notice` with the copyable next command
  (`git add <p> && git rebase --continue` / `git merge --continue` / `git cherry-pick --continue`) or
  "resolved in the working tree, not yet staged". Loads via `conflict(generation, id)` with the same
  gates as `fileDiff` (large sides → Load button; binary → BinaryNotice).
- Reflog panel: History mode `Reflog` sub-tab list (T11.5 owns the sidebar shell; this task ships the
  `ReflogList` component and the store slice `reflog: ReflogEntry[]`, rendered by T11.5; until then it
  is reachable from the palette action "Show reflog" as a popover). Rows: `HEAD@{n}`, action, message,
  age, `unreachable` badge (fill via `markReachable` in batches of 50), click → range source of that
  commit (T11.2 `setSource`).
- Sidebar: conflict rows already exist; the card header shows `both modified` etc. as a `ref`-style tag.

## Tests

  three columns and markers on the recorded `rebase-conflict` payload; resolved state; reflog list with
  unreachable badge; a11y.
