# T11.11 — Multi-repo dashboard on Home

**Size:** M · **Depends on:** T11.10, T10.10 · Design §14.6 · Atlas tab 11

## Deliverables
- `RepoCard` grid replacing the RecentRow list (keep RecentRow for the nav popover): name, branch,
  ahead/behind vs upstream, `LayerChip`s with counts, operation tag, `secret`? no (not scanned here),
  last commit age, `Open` / `Re-authorise`; cards show the cached summary immediately.
- Background summariser: for repositories with `granted` permission, sequentially, only while Home is
  visible, cancel on navigation; `summarise()` through a second short-lived worker client
  (`engineClient.summaryClient()`), cache in `derived` keyed by repoId with `indexMtimeMs`;
  skip when the cached mtime matches a cheap `stat` of `.git/index` done by the client (`fileStat`
  helper on the engine `open`-less path: add `statIndex(handle)` to `EngineApi` if needed — note it in
  the contracts file).
- `Refresh all` button; per-card error state (`HANDLE_GONE`, `PERMISSION`) using existing copy.

## Tests
- Cards render from cache, summaries fill in order, permission states, cancel on unmount, no
  summarise for `prompt` repos; a11y.
