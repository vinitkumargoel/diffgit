# T11.5 — History mode: commit list, lanes, details, ranges, stack, reflog tab

**Size:** L · **Depends on:** T11.4, T10.5 · Design §14.5 · Atlas tabs 03, 04

## Deliverables
- `HistoryView`: sidebar replaced by `CommitList` (virtualised, rows per §14.5, SVG lanes from
  `CommitSummary.edges`, refs badges, `+n −m` via `commitStats` for visible rows, infinite scroll via
  `cursor`, `capped` banner `HISTORY_CAPPED`); row 1 `Commits | Stack | Reflog` + count; row 2 search
  input (filters loaded commits client-side; Enter with no local match runs `search({scope:"commits"})`)
  and `first-parent` / `all branches` toggles.
- Selection: click → `RangeSource{commit}` (parent…commit, root → empty tree); Shift-click → range
  `older…newer`; the diff pane shows `CommitCard` (§14.5) then the FileCards; StatsRow counts follow.
- `CommitCard`: subject, body (collapsed after 6 lines), author/committer/date, parents (clickable),
  tree, `signed`, note, refs; actions `Show diff`, `Compare with base…` (sets base…commit), `Copy SHA`,
  `…` menu with `Export as .patch` (T11.10 wires), `Copy cherry-pick command`, `Bisect: mark good/bad`
  (T11.13 wires; hidden until then), `Blame here` (T11.6 wires).
- `Stack` tab: commits of compare since the merge base newest-first as collapsed cards (subject, SHA,
  files, `+n −m`), expand → per-commit FileCards (lazy compute on a secondary generation; reuse the
  DiffPane with a `source` prop), `Uncommitted` entry on top when the worktree is included.
- `Reflog` tab renders T11.3's `ReflogList`.
- Keyboard: `j`/`k` move the selection in the list; `Enter` shows; `Escape` back to Files? No — modes
  are explicit (`1`).
- Mock client recordings of `walkCommits`/`commitDetails`/`commitStats` from `history`.

## Tests
- List renders rows and lanes (structural: edge count per row), infinite scroll requests the cursor,
  search filters, first-parent toggle re-requests, selection → source, shift-range, CommitCard content,
  stack cards expand, reflog tab; a11y on the list (roles `listbox`/`option`) and the card.
