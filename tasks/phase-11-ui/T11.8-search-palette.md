# T11.8 — Search scopes in the palette

**Size:** M · **Depends on:** T11.7, T10.8 · Design §14.1 (palette) · Atlas tab 05

## Deliverables
- Palette scopes by prefix: `>` commits, `grep:` working tree, `-S` pickaxe (scoped: current file
  filter path if any, `commits` default 200 with `Widen ×5` up to 5,000); results grouped, streamed
  (poll `search` once; show `scanned`, duration, `capped`), hit → commit selection (History) or file
  (Files, scroll to line via the existing scroll bus); `Escape` cancels the in-flight search
  (`cancel` through a new `cancelSearch` client call if the engine exposes one; else ignore result).
- A palette footer line explains the prefixes; `regex:` modifier toggles regex.

## Tests
- Each scope calls the client with the right request; results render and navigate; widen; cancel;
  a11y.
