# T11.6 — Blame and file history in the file card

**Size:** L · **Depends on:** T11.5, T10.6 · Design §14.1 (FileHeader) · Atlas tab 02

## Deliverables
- FileHeader mini control `Diff | Blame | History` (store `cardModes[id]`, keys `b` / `h` on the active
  card), shown only when the file has a committed side; `…` menu on the header with `Why is this file
  shown like this` (T11.4 popover), `Copy path`, `Export this file as .patch` (T11.10).
- `BlameBody.tsx`: gutter columns per the atlas (6 px age strip using `--heat1..5` by age quintile,
  author, short SHA `--accent`, line number, code with Shiki highlighting through the existing
  highlight worker); uncommitted lines `you, uncommitted` in `--attention`; rows for the same commit
  collapse the author/SHA (shown once per run); hover/click popover: subject, author, date, `Show
  commit diff` (→ History selection), `Blame at parent` (re-blames at `oid^`); toggle `Ignore
  whitespace-only commits` (default on) mapped to `ignoreWhitespace`; progressive: render as soon as
  the payload arrives, with a `revisions` counter and `capped` notice (`Continue` raises
  `maxRevisions`); cached in `derived` by `(repoId, oid, path, w)`.
- `FileHistoryBody.tsx`: list of `PathHistoryEntry` (SHA, subject, author, age, `renamed` / `ws only`
  tags), `Load more`; click → select that commit in History mode with the file scrolled into view;
  `Follow renames` toggle.
- Progress phase `blame` in the LoadingSkeleton for the card.

## Tests
- Header control visibility rules; `b`/`h` keys; blame body renders runs, heat classes, uncommitted
  rows, popover actions; capped → Continue; whitespace toggle re-requests; history list and Load more;
  derived cache hit skips the worker call; a11y (blame is a `table` with headers).
