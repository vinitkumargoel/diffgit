# T11.14 — Install, file handler, persistent permissions, patch-only mode

**Size:** M · **Depends on:** T11.13, T10.12 · Design §14.6 · Atlas tab 17

## Deliverables
- `public/manifest.webmanifest` (name, icons from `favicon.svg` + PNG sizes generated by
  `scripts/screenshots.ts` or a new `scripts/icons.ts`, `display: standalone`, `file_handlers` for
  `.patch`/`.diff`/`text/x-patch`, `launch_handler: { client_mode: "navigate-existing" }`); service
  worker `public/sw.js` precaching the built assets (list generated at build by a small Vite plugin);
  header change `connect-src 'self'` **only for the service-worker scope is not possible** — change
  `public/_headers` to `connect-src 'self'` and extend `e2e/privacy.spec.ts` to assert zero requests
  to any host after load *and* zero non-same-origin requests during the whole session; document in
  `docs/privacy.md` why `'self'` is needed and what still blocks.
- `Install` button in row 1 while `beforeinstallprompt` is pending; `launchQueue.setConsumer` →
  read the file → `parsePatch` → patch-only screen (banner `PATCH_ONLY`, FileCards, no sidebar
  groups, no refresh) ; drag-and-drop of a `.patch` anywhere on Home or the repo screen does the same;
  with a repository open, a `Check against working tree` action reports whether each file's old side
  matches the current blob (cheap: compare `oldOid` when present).
- Persistent permission: after `requestPermission` succeeds inside an installed app, nothing to do;
  on Home show a one-line hint "Install diffgit to skip the permission prompt on every visit" when
  not installed and ≥ 2 recents exist (dismissible, pref).

## Tests
- Manifest validity (JSON schema-lite test), SW precache list matches `dist` (in `check-dist.sh`),
  patch-only render from a recorded patch, drop handler, install button visibility; e2e privacy spec
  extended as above.

- [ ] `bun run check` and `bun run e2e` green; Lighthouse PWA installability verified manually by the
  owner (note in CHANGELOG as owner step).
