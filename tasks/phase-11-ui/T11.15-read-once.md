# T11.15 — Firefox and Safari read-once (snapshot) mode

**Size:** M · **Depends on:** T11.14 · Design §14.6 · Atlas tab 18

## Deliverables
- BrowserGate: on engines without `showDirectoryPicker`, a primary `Open a repository once` button
  (`<input type=file webkitdirectory>`), explanation copy from the atlas, a streaming counter while the
  browser enumerates (entries seen; abort with advice above 100,000), then build a `MemoryDirHandle`
  tree lazily reading bytes only on demand (`file.arrayBuffer()` when the engine asks; never for
  files outside `.git` unless the diff needs them), open the session with it, `snapshotMode: true`:
  no scheduler, no recents, StatsRow tag `Snapshot mode · read at <time> · Re-open to refresh`
  (`SNAPSHOT_MODE` warning at attention level), Live dot hidden.
- Works in Chromium too (palette action `Open once (snapshot)`), which is how it is tested.

## Tests
- Memory handle builder from a `FileList`-like array; lazy reads (bytes read only for requested
  files); gate rendering per engine; snapshot tag; scheduler not started; e2e: none (policy).
