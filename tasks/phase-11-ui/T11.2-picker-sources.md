# T11.2 — Compare anything in the pickers

**Size:** M · **Depends on:** T11.1, T10.1 · Design §14.1 (BranchPicker) · Atlas tab 10

## Deliverables
- BranchPicker: groups `Tags` (badge `tag`, `--chip-M` palette), `Stashes` (`stash@{n}`, message,
  file count, age; badge palette of `T`), `Special` (`Working tree`, `Staged only` — only in the
  compare picker); free-text row "Use `<text>`" when the query is not an exact ref name, resolving via
  `resolveRevision` on Enter with an inline error (`REV_NOT_FOUND`, `REV_AMBIGUOUS` listing
  candidates); footer `three-dot … | two-dot ..` toggle (pref `twoDot`, tooltip explains merge base).
- Store: `setSource(rev: ResolvedRevision, side)` builds a `RangeSource` when either side is not a
  branch, otherwise keeps `BranchesSource`; `includeWorktree` rules via `isWorktreeSource`;
  `selectSourceLabel` for the StatsRow (`v2.3.0 … stash@{0}`); the swap button works for ranges.
- URL hash `#compare=<from>...<to>` (`..` for two-dot) written on change and read on open (after
  the repository is open; unresolvable → toast + default source). Hash state is the only "deep link".
- `IncludeWorktreeToggle` disabled with the existing info banner when `to` is not HEAD.
- Mock client: `resolveRevision`, `listTags`, `listStashes` from recordings of `history`/`stash`.

## Tests
- Picker shows the groups with counts, free text resolves, errors render inline, two-dot toggle changes
  the source and the StatsRow label, hash round-trip, swap on a range, worktree toggle disabled state;
  a11y for the extended popover.
