# T11.13 — Bisect strip and rebase preflight panel

**Size:** M · **Depends on:** T11.12, T10.11 · Design §14.5 (Bisect), §14.6 (Preflight) · Atlas tabs 15, 16

## Deliverables
- Bisect: start from the palette (`Start bisect…` → pick good and bad from the commit list) or the
  CommitCard menu (`mark good` / `mark bad`); `BisectStrip` above the commit list with the range,
  remaining, steps, candidate (selected in the list), `Good` (`g`) `Bad` (`x`) `Skip` `Stop`, copyable
  `git checkout <sha>`; warn when the working tree is dirty; state in `derived` per repo; when HEAD
  equals the candidate (live refresh) the strip says "you are on the commit under test"; result state
  `first bad commit: <sha>` with `Show`.
- Preflight: `PreflightPanel` in the Branches mode body (replaces the table while open): table per
  §14.6 with prediction chips, `git rebase -i …` command, `Copy todo`, signed/merge notes; opened from
  the row menu or palette (`Preflight rebase of compare onto base`).

## Tests
- Bisect flow on recordings (start → steps → result), keys, dirty warning, persistence; preflight
  table renders predictions and copies the todo; a11y.
