# T2.2 — Blob hashing (git SHA-1)

**Phase:** 2 · **Size:** S · **Depends on:** T0.4 · **Blocks:** T2.4, T3.3
**Plan refs:** §5.5 step 2, §1 finding 7

## Goal
Compute `git hash-object` values for file contents in browsers and Bun.

## Deliverables
- `src/engine/git/hash.ts`:
  - `hashBlob(bytes: Uint8Array): Promise<Oid>` → SHA-1 of `"blob <len>\0" + bytes`.
  - `hashBlobStream(stream: ReadableStream<Uint8Array>, size: number): Promise<Oid>` for files > 8 MB (chunked; if `crypto.subtle` cannot stream, fall back to a small pure-JS SHA-1 implementation — include one, ~100 lines, MIT-licensed or written here).
  - `sha1(bytes): Promise<Uint8Array>` used by T2.1's checksum.
  - `toHex(bytes)`.

## Tests
- `hash-object.json` parity for the sample files in `fixtures/basic`.
- Empty file → `e69de29bb2d1d6434b8b29ae775ad8c2e48c5391`.
- Stream vs buffer equality on the 11 MB file in `large`.
