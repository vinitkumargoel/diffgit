# T3.1 — Tree diff (flattened tree A vs B)

**Phase:** 3 · **Size:** S · **Depends on:** T1.3 · **Blocks:** T3.2
**Plan refs:** §5.6 step 4

## Goal
Compute per-path changes between two flattened trees, including mode and type changes, in path order.

## Deliverables
- `src/engine/diff/treeDiff.ts`: `treeDiff(a: FlatTree | null, b: FlatTree | null): Record<string, Change>` (`Change` from T2.4). `null` tree = empty (unborn / no merge-base handling in T3.2).
- Rules: path only in `a` → deleted; only in `b` → added; both with different oid **or** mode → modified. Symlink ↔ file (`120000` ↔ `100644`) and submodule (`160000`) changes are still emitted as modified; T3.4 labels them `typechange`. Gitlinks (`160000`) never have blob content: mark `oldOid/newOid` but T3.4 renders a "Submodule commit changed" notice.

## Tests
`name-status-3dot-no-renames.json` parity on `basic`, `renames` (with `--no-renames`), `binary`, `symlink`; ordering equals git's (byte-wise path sort).

## Acceptance criteria
- [ ] Parity green; function is pure and O(|a|+|b|).
