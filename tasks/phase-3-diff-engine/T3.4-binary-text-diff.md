# T3.4 — Binary/image detection, content loading, text diff & stats

**Phase:** 3 · **Size:** M · **Depends on:** T3.2 · **Blocks:** T3.5
**Plan refs:** §5.6 steps 7–9, §6.7 limits, §4 (`FileContents`)

## Goal
Load both sides of a file, classify it, compute `+/-` stats and the hunk model the UI renders, with whitespace-ignore support and size gating.

## Deliverables
- `src/engine/diff/binary.ts`: `isBinary(bytes: Uint8Array): boolean` (NUL in first 8000 bytes), `isImagePath(path)`, `BINARY_EXTENSIONS` list (fonts, archives, media, `.pdf`, `.class`, `.wasm`, ...).
- `src/engine/diff/contentLoader.ts`: `loadSides(file: FileDiff): Promise<FileContents>` using the side-table from T3.2 (`tree`/`index` → `db.readBlob`, `worktree`/`untracked` → fs read). Submodule (`160000`) → contents `null` with `kind: "submodule"`.
- `src/engine/diff/textDiff.ts`:
  - `computeStats(contents, opts): { additions, deletions }` using jsdiff `diffLines` (or `structuredPatch`) with `ignoreWhitespace` option → per-line changes; binary → `null`.
  - `computeHunks(contents, opts: { context: 3, ignoreWhitespace }): HunkModel` — a serialisable model:
    ```ts
    interface HunkModel { oldLines: number; newLines: number; hunks: { oldStart, oldCount, newStart, newCount, lines: { type: "ctx"|"add"|"del"; old?: number; new?: number; text: string }[] }[]; }
    ```
    (If Spike S1 picks `@git-diff-view`, expose in addition the `generateDiffFile`-compatible inputs — old/new text + language; the hunk model is still needed for stats and for the fallback renderer.)
  - `classify(file, contents): { binary, image, tooLarge, typechange, submodule }` with limits: `> 1 MB` either side or `> 3000` changed lines → `tooLarge = true` (UI gates); `> 10 MB` → `tooLarge` + warning `FILE_TOO_LARGE`, hunks not computed.
  - `typechange` when modes differ in type (`100644/100755` ↔ `120000` ↔ `160000`).
- `languageFor(path): string` — extension → Shiki/lowlight language id map (top ~60 languages), `"text"` fallback.

## Tests
- `numstat.json` parity (`basic`, `renames`, `binary` incl. `-` for binaries) with `ignoreWhitespace=false`.
- `isBinary` on the `.bin`, PNG, SVG (text!), and the text file that gains a NUL.
- `large` fixture: 3000-line file `tooLarge`, 1.5 MB `tooLarge`, 11 MB not computed + warning.
- `symlink` → `typechange`; hunks show link target text.
- Whitespace-ignore: a file with indentation-only changes has stats `{0,0}` and no hunks when ignored.

## Acceptance criteria
- [ ] Green; `computeHunks` on a 3000-line changed file < 300 ms.

## Amendments (review round 1)
- **Whitespace toggle = `git diff -w`**: normalise each line by removing **all** whitespace before comparing (jsdiff's `ignoreWhitespace` only trims edges). Display the original lines. Expose `whitespaceOnly: boolean` when the `-w` hunk set is empty but the exact one is not (UI shows "Whitespace changes only"). Parity: `numstat-w.json`.
- **Binary classification = git's**: NUL-in-first-8000-bytes **or** `.gitattributes` (`binary`, `-diff`, `-text` treated as binary; `diff=<driver>` unsupported → treat as text). Drop the extension-based binary list. Keep `isImagePath` (rendering hint only). Parse `.gitattributes` at repo root and per directory (`src/engine/git/attributes.ts`, same layering as ignore rules; patterns use gitignore syntax without negation semantics — `!` is not allowed in attributes).
- `linguist-generated` (and `linguist-generated=true`, `-diff`) → `FileDiff.generated = true`; the UI collapses these by default like GitHub. Add `generated?: boolean` to `FileDiff`.
- Tests added: `attributes` fixture (`*.dat` binary in numstat as `-`, `*.lock` collapsed, `generated/**` flagged).
