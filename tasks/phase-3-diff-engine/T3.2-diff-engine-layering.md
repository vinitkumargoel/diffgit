# T3.2 — DiffEngine: merge-base compare + working-tree layering

**Phase:** 3 · **Size:** L · **Depends on:** T3.1, T2.4, T1.4 · **Blocks:** T3.3, T3.4
**Plan refs:** §5.6 steps 1–5 and 8, D5, D6, D7, §4 (`DiffSource`, `FileDiff`, `DiffResult`)

## Goal
Given a `DiffSource`, produce the file list with the correct "old side" (merge-base) and "new side" (source tip, or index/worktree when layered), with layer badges.

## Deliverables
- `src/engine/diff/diffEngine.ts`:
  ```ts
  class DiffEngine {
    constructor(db: ObjectDb, refs: RefSnapshot, scanner: WorktreeScanner, readIndex: () => Promise<IndexSnapshot>)
    compute(src: DiffSource, signal?: AbortSignal): Promise<{ files: FileDiff[]; mergeBase: Oid | null; warnings: RepoWarning[]; worktree?: WorktreeStatus }>
  }
  ```
  (Renames, binary flags, stats are filled by T3.3/T3.4; this task sets `status` ∈ added/modified/deleted and leaves `similarity`, `binary`, `stats` defaulted.)
- `resolveBranchName(name)`: accepts `"main"`, `"origin/main"`, `"refs/heads/x"`, `"refs/remotes/o/x"`; errors `REF_NOT_FOUND` with the name.

## Algorithm
1. Resolve `sourceOid`, `targetOid`. Unborn source → `sourceTree = null`.
2. `includeWorktree` applies only if `src.source` is the local checked-out branch (`refs.headBranch`) **or** the repo is detached/unborn and the source is `"HEAD"`. Otherwise force `includeWorktree=false` and add warning `WORKTREE_NOT_APPLICABLE` (UI disables the toggle; engine still guards).
3. If `sourceOid === targetOid` and no worktree layer → empty result, `mergeBase = sourceOid`.
4. `mergeBase = findMergeBase(source, target)`; `null` → warning `UNRELATED_HISTORIES`, `baseTree = null` (two-dot against empty is wrong; use `targetTree` as base instead so the diff is "source vs target" two-dot: document this choice in code).
   If `sourceOid === targetOid` with worktree layer → `baseTree = sourceTree`.
5. `committed = treeDiff(baseTree, sourceTree)`.
6. Worktree layer (when applicable): `index = readIndex()`, `wt = scanner.scan(index, sourceTree)`.
   Build `final: Record<path, { old: {oid,mode}|null; new: {oid,mode,kind:"tree"|"index"|"worktree"|"untracked"}|null; layers: Set<ChangeLayer> }>`:
   - start from `committed` (layers `{committed}`), old = base, new = source tree.
   - for each `wt.staged[p]`: new = index entry (oid from index), add `staged`.
   - for each `wt.unstaged[p]`: new = worktree (`newOid` may be known from hashing; deleted → new = null), add `unstaged`.
   - for each `wt.untracked`: new = worktree file (oid unknown until read: set `newOid = null`, `kind: "untracked"`), add `untracked`.
   - conflicts: layers add `conflict`; new side = worktree file as-is.
   - for each path in `final` that was **not** in `committed`: old = `baseTree[p] ?? null`.
   - **elimination**: drop entries where `old?.oid === new?.oid && old?.mode === new?.mode` (e.g. edited on the branch then reverted in the worktree to base content; untracked files are never eliminated).
7. Map to `FileDiff[]`: `status` = added (old null) / deleted (new null) / modified; `id = newPath ?? oldPath`; `layers` array in the fixed order committed, staged, unstaged, untracked, conflict; sort by path.
8. Attach `newSide.kind` in a private side-table (not in `FileDiff`) so T3.4 knows where to load content from: `tree` → `readBlob`, `index` → `readBlob(indexOid)`, `worktree`/`untracked` → read file bytes.
9. Honour `signal` between steps.

## Tests
- `basic`/`packed`/`remote`: files & statuses == `name-status-3dot-no-renames.json`; `mergeBase == merge-base.json`.
- `basic` with source=target → empty.
- `worktree` fixture (source = `feature` = HEAD, includeWorktree): expected built in T0.3 from `git diff --no-renames --name-status <base>` run in the worktree **plus** untracked files as added; check every layer badge case, including the file that is both staged and unstaged (`layers = [staged, unstaged]`) and the reverted file (eliminated).
- `worktree` with `includeWorktree=false` → equals committed-only.
- Source = a non-checked-out branch with `includeWorktree=true` → warning `WORKTREE_NOT_APPLICABLE`, no worktree layer.
- `unrelated` → warning, non-empty file list.
- `unborn` → all index entries added with `staged` layer.
- `conflict` → conflict layer present.
