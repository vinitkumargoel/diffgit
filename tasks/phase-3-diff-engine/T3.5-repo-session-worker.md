# T3.5 — RepoSession orchestrator + Web Worker entry

**Phase:** 3 · **Size:** M · **Depends on:** T3.3, T3.4, T1.2, T1.4 · **Blocks:** T6.1, T4.1 (real worker)
**Plan refs:** §3, §5.2–5.7, §4 (`RepoInfo`, `DiffResult`)

## Goal
One object per open repo that exposes the whole engine to the UI over comlink, with progress, cancellation and typed errors.

## Deliverables
- `src/engine/session.ts`:
  ```ts
  class RepoSession {
    static async open(root: DirHandleLike, onProgress: (p: Progress) => void): Promise<RepoSession>   // layout → config → refs → index caps
    info(): RepoInfo
    async reloadRefs(): Promise<RepoInfo>                              // after refresh detects .git changes
    async computeDiff(src: DiffSource, onProgress): Promise<DiffResult> // cancels any in-flight compute (generation counter)
    async fileStats(ids: string[]): Promise<Record<string, FileDiff["stats"]>>  // batched lazy stats
    async fileDiff(id: string, opts: { ignoreWhitespace: boolean }): Promise<{ hunks: HunkModel | null; classification; oldText?: string; newText?: string; language }>
    async fileBytes(id: string, side: "old" | "new"): Promise<Uint8Array | null>   // images
    invalidate(scope: "refs" | "worktree" | "all"): void               // clears fs handle cache / trees / stat cache
    forceRehash(): void
    close(): void
  }
  type Progress = { phase: "refs" | "index" | "worktree" | "diff" | "renames" | "stats"; done?: number; total?: number };
  ```
- `src/engine/worker.ts`: `Comlink.expose({ open, ... })` — handles are received via `postMessage` (structured clone of `FileSystemDirectoryHandle`), progress via `Comlink.proxy` callbacks. Keeps a single active session; `open` closes the previous.
- Error mapping: every thrown error crossing the boundary is serialised as `{ code, message, hint? }` (comlink loses prototypes); UI maps codes to copy (T4.1).
- Generation counter: `computeDiff` increments `gen`; scanner/engine get an `AbortSignal` tied to it; a superseded call rejects with `CANCELLED`.

## Tests
- Session integration on `worktree`: `open` → `computeDiff` (default source/target from `RepoInfo`) → `fileStats` → `fileDiff` for a text file, an image, a binary → results consistent with Phase 2/3 tests.
- Two overlapping `computeDiff` calls: the first rejects `CANCELLED`, the second resolves.
- `invalidate("worktree")` after mutating a file via `memoryDirHandle` → next compute sees the change.
- Worker boundary test in vitest (happy-dom + a real `Worker` via Vite's `?worker` in a browser-mode test, or a fake `MessageChannel`): errors arrive with `code`.

## Amendments (review round 1)
- **`probe()` lives here** (moved from T6.3): `probe(tier: "git" | "index" | "untracked"): Promise<string>` returns a signature string per tier — `git`: `lastModified+size` of `.git/HEAD`, `.git/index`, `.git/packed-refs`, loose ref files for current source/target/HEAD branch, `.git/refs/remotes/*/HEAD`, `.git/config`, `.git/info/exclude`; `index`: hash of `(path,size,lastModified)` over stage-0 entries (no content reads); `untracked`: count + hash of paths from an ignore-pruned walk. Each tier reports its own duration in `Progress`.
- **Generation**: `computeDiff` stamps `DiffResult.generation`; `fileDiff/fileStats/fileBytes(generation, ...)` reject `STALE` when it is not current, so no result from an old side-table can be served.
- **Worker-owned background stats**: after `computeDiff` resolves, the worker computes stats for all files in a LIFO priority queue; the UI calls `prioritise(ids)` for visible rows and receives `onStats(batch)` callbacks over the single progress channel. Cancelled on the next `computeDiff`. `fileStats()` remains for on-demand cases.
- **Stale pack**: `ENOENT` inside object reads → `db.dropCaches()`, `invalidate("all")`, retry the whole compute once, add `STALE_PACK_RETRIED`.
- **Public error translation** at the boundary per `tasks/README.md`; `ENOENT` on the root handle (folder deleted/moved) → `HANDLE_GONE`.
- **Single progress channel**: `open(handle, channel: Comlink.Remote<ProgressSink>)` registers one proxied sink for the session; no per-call `Comlink.proxy` (each one opens a port that is never released).
- Tests added: `probe` tier signatures change on the right mutations on `worktree` and `perf-5k` timing per tier (`git` < 30 ms, `index` < 300 ms in bun, `untracked` < 600 ms); `STALE` rejection after recompute; pack swap mid-session recovers.
