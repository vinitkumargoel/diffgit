# T10.4 — Why is this file hidden: rule attribution, hidden listing, index flags

**Size:** M · **Depends on:** T10.3 · Atlas tab 08

## Deliverables
- `src/engine/git/ignoreRules.ts`: `explain(path, isDir): { source: string; line: number; pattern: string; negated: boolean } | null`
  — the last matching rule in precedence order (`.gitignore` chain nearest-first, `info/exclude`,
  built-ins), matching `git check-ignore -v` output; keep `IgnoreRules.isIgnored` behaviour unchanged.
- `src/engine/git/explain.ts` (new): `explainPath(session, path)` → `PathExplanation` combining: ignore
  rule, `IndexEntry.skipWorktree` / `assumeValid` / `isSparseDir`, size gates (`HUGE_FILE_BYTES`),
  `generated` attribute, or `clean` (tracked, unchanged). `command` filled per reason
  (`git check-ignore -v <p>`, `git update-index --no-skip-worktree <p>`, `git update-index --no-assume-unchanged <p>`).
- `listHidden()` in the scanner: ignored directories as one entry with `count` of direct children
  (never descend), ignored files at the visited level, skip-worktree / assume-unchanged entries from the
  index, `too-large` from the last diff's classification; cap 2,000 (`HIDDEN_CAPPED`). Must not slow the
  normal scan: run only on demand.
- `SessionOptions.builtinExcludes` wired from `open()` options (`OpenOptions.builtinExcludes`, default
  true) so the UI pref (B10) reaches `IgnoreRules`.
- `EngineApi.explainPath`, `EngineApi.listHidden`.
