# T10.1 — Range sources, revision resolver, tags, stashes

**Size:** L · **Depends on:** T10.0 · Atlas tab 10

## Deliverables
- `src/engine/errors.ts`: the v2 warning and public codes from `docs/v2-contracts.md`.
- `src/engine/git/hash.ts`: `EMPTY_TREE_OID`.
- `src/engine/types.ts`: `RangeSource`, `ResolvedRevision`, `TagInfo`, `Signature`, `StashInfo`
  exactly as in the contracts; `DiffSource` becomes the union. `src/engine/diffSource.ts`:
  `isWorktreeSource` handles `RangeSource`.
- `src/engine/git/revisions.ts` (new): `resolveRevision(db, refs, expr)` supporting full refs, `HEAD`,
  short names in git's precedence (`refs/<x>`, `refs/tags/<x>`, `refs/heads/<x>`, `refs/remotes/<x>`,
  `refs/remotes/<x>/HEAD`), 7–40 hex SHA prefixes over loose + packed objects (`REV_AMBIGUOUS` with
  candidates in `detail`), `~n`, `^`, `^n`, chains (`main~2^2`), `stash@{n}`, annotated-tag peeling.
  `<root>^` resolves to `{oid: null, kind: "empty-tree"}`. Unknown → `REV_NOT_FOUND`.
- `src/engine/git/tags.ts` (new): `listTags(db)`; annotated tags read with `git.readTag`.
- `src/engine/git/stash.ts` (new): `listStashes(fs, db)` from `.git/logs/refs/stash` (newest first,
  index 0 = last line), commit parents → `baseOid`, `indexOid`, `untrackedOid` (third parent or null);
  `files` = size of tree diff base→stash (compute lazily, may be null).
- `DiffEngine.compute` accepts `RangeSource`: three-dot → merge base of `fromOid`/`toOid` as today;
  two-dot → `fromOid` tree directly; `fromOid === null` → empty tree; worktree layering only when
  `isWorktreeSource`. `DiffResult.source` echoes the source. A stash as `to` layers its index tree as
  `staged` and its untracked tree as `untracked` (`layers` filled accordingly) — this is how the UI shows
  "3 files (1 untracked)".
- `RepoSession` + `EngineApi`: `resolveRevision`, `listTags`, `listStashes`; `computeDiff(RangeSource)`.
- `src/ui/workerClient.mock.ts` and recorded mocks: extend so UI tests can pass ranges (record the
  `history` fixture with `bun run record`).

## Tests (bun)
- Resolver on `history`/`tags`/`stash`: every form above; expectations from `git rev-parse` recorded by
  T10.0; ambiguity with a crafted 4-char prefix → `REV_AMBIGUOUS`; `REV_NOT_FOUND` on garbage.
- `listTags` equals `git tag -l --format='%(refname) %(objectname) %(*objectname)'`.
- `listStashes` equals `git stash list --format='%gd %H %s'` and the `-u` stash has `untrackedOid`.
- Range diffs: `a..b` equals `git diff --name-status a b`; `a...b` equals `git diff --name-status a...b`;
  single commit equals `git show --name-status --format=`; root commit vs empty tree; stash source shows
  the untracked file under `untracked`.
