# T10.5 — Commit walker, commit-graph reader, lanes, refs by commit, ahead/behind, branch overview

**Size:** L · **Depends on:** T10.4 · Atlas tabs 03, 09, 20

## Deliverables
- `src/engine/git/commitGraph.ts` (new): reader for `.git/objects/info/commit-graph` (single file;
  chains → fall back, `COMMIT_GRAPH_STALE` never thrown, just `graphAvailable: false`): header, OID
  fanout (`OIDF`), lookup (`OIDL`), commit data (`CDAT`: tree, two parents or edge list `EDGE`,
  generation, commit time). Lookup `oid → {parents, time}` in O(log n). Any oid absent from the graph
  → object read fallback. Verify the trailing checksum.
- `src/engine/git/walk.ts` (new): `walkCommits(req)` — priority queue by commit time (ties by
  insertion), `firstParent`, `all` (every ref in `RefSnapshot` + stash oids), optional `path` filter
  (commit kept when the path's blob differs from first parent; use `flattenTree`, memoised), page by
  `limit`, opaque `cursor` (serialised frontier); cap 50,000 commits per walk (`HISTORY_CAPPED`).
  Lane assignment: first-fit lanes carried across pages via the cursor, `edges` per row for the SVG.
  `refs` per commit from a `Map<Oid, string[]>` built from `RefSnapshot` + tags + stashes.
- `commitDetails(oid)`: body, tree, `signed` (`gpgsig` header present), note from
  `refs/notes/commits` (isomorphic-git `readNote`, null when absent), `stats` via `commitStats`.
- `commitStats(oids)`: tree diff vs first parent (root → empty tree) + `numstat` from
  `computeStats` on text blobs, batched 16 at a time with the existing stats concurrency limit.
- `aheadBehind(a, b)`: merge base + `rev-list --left-right --count` semantics, cap 10,000 each.
- `branchOverview()` / `branchCells(names)`: rows for every ref with `upstream` from config
  (`branch.<n>.remote` + `.merge`), `lastCommit` from the tip; cells computed on demand.
- `markReachable(oids)`: one walk from all refs (cached per refs generation) → membership.
- `RepoInfo.hasCommitGraph` already set by T10.2; `WalkPage.graphAvailable` reflects use.
- `EngineApi`: `walkCommits`, `commitDetails`, `commitStats`, `aheadBehind`, `branchOverview`,
  `branchCells`, `markReachable`. Progress phase `"history"`.

## Tests
- `history`, `octopus`, `crisscross`, `detached`, `perf-5k`: commit order equals
  `git log --date-order --format=%H` (with and without `--first-parent`, with `--all`); path walk equals
  `git log --format=%H -- <path>`; lanes: every parent edge connects consecutive rows (structural
  test) and lane count ≤ 12 on `history`; `aheadBehind` equals `git rev-list --left-right --count`;
  commit-graph reader returns the same parents/time as `readCommit` for every commit in `history`, and
  the walk uses it (`graphAvailable: true`); reflog `reachable` true/false matches `git branch
  --contains`; `commitStats` equals `git show --numstat`.
- Perf (`scripts/perf.ts`): first page of 50 on `perf-5k` < 100 ms; full walk of `history` printed.
