# T10.0 — v2 fixtures

**Size:** M · **Depends on:** T0.3

## Deliverables
- `scripts/make-fixtures.sh`: add the fixtures listed in `docs/v2-contracts.md` § "Fixtures to add"
  (`tags`, `stash`, `rebase-conflict`, `merge-conflict`, `reflog-orphan`, `history`, `secrets`,
  `hidden`, `octopus`). Build them with the real git CLI only; deterministic authors, dates
  (`GIT_AUTHOR_DATE`/`GIT_COMMITTER_DATE`), and messages. `history` must contain: ≥ 60 commits, two
  branches with one merge, a root commit, a file renamed with a small edit (`git mv` + edit), a
  whitespace-only commit (indent change), a `.mailmap` mapping one author's two emails, an author named
  `renovate[bot]`, three lightweight and one annotated tag, and `git commit-graph write --reachable
  --changed-paths`. `rebase-conflict` is left mid-rebase (`git rebase -i` with `GIT_SEQUENCE_EDITOR=true`
  stopped by a conflict at step 2 of 3). `merge-conflict` is left mid-merge with `MERGE_HEAD`, one `UU`
  file, one modify/delete. `secrets` plants `AKIA…` (AWS), `ghp_…`, `sk-ant-api03-…`, a `-----BEGIN RSA
  PRIVATE KEY-----` block and a 40-char hex sha (must NOT be flagged), plus one line ending in
  `# diffgit:allow-secret`. `hidden` has `dist/` ignored with 3 files, `.env.local` ignored, a
  `skip-worktree` file, an `assume-unchanged` file and an 11 MB file committed and then modified.
- `scripts/fixture-expectations.sh`: per fixture, record git's output as named in the contracts
  document under `fixtures/<name>/expected/*.txt`.
- `fixtures/README.md` rows for each.
- `src/test/fixtures.ts`: expose the new names.

## Acceptance
- [ ] `bun run fixtures` builds all new fixtures; `git status` inside each matches the description.
- [ ] Every expectation file exists and is non-empty; `git blame --porcelain` for `history`'s renamed file is recorded.
- [ ] `bun run check` green (existing tests untouched).
