# T10.9 — Insights aggregation

**Size:** M · **Depends on:** T10.8 · Atlas tab 13

## Deliverables
- `src/engine/git/mailmap.ts`: parse `.mailmap` (name/email mapping forms of `git help mailmap`).
- `src/engine/insights/insights.ts`: walk first-parent from `HEAD` (cap 50,000, `INSIGHTS_CAPPED`),
  filter by `sinceMs`; per commit: path-level tree diff vs parent (Bloom filters from the commit-graph
  when present to skip unchanged paths is optional; note if done); accumulate per-path commit counts
  and per-author counts (mailmap applied; authors matching `/\[bot\]$/i` or `/^dependabot|renovate/i`
  counted in `bots` and excluded); `hotspots` = top `limit` by `commits × log2(size)` where size is the
  blob size at HEAD, `manifest` true for `package.json`, lockfiles, `go.sum`, `Cargo.lock`, etc. (excluded
  from ranking but returned); `activity` = commits per day for the last 52 weeks (author date, local
  midnight buckets). Progress `"insights"`.
- `EngineApi.insights`; abortable; one in flight.

## Tests

  counted; hotspot top-3 equals `git log --format= --name-only | sort | uniq -c` top-3 for non-manifest
  paths; activity sums to the commit count in the window.
