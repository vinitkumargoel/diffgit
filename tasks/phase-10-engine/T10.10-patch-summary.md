# T10.10 — Patch text and repository summary

**Size:** M · **Depends on:** T10.9 · Atlas tabs 12, 11

## Deliverables
- `src/engine/diff/patchText.ts`: `patchText(generation, ids | null)` — git-format unified diff for the
  current `DiffResult`: `diff --git a/x b/x`, `similarity index`/`rename from/to`, `new file mode`,
  `deleted file mode`, `old mode`/`new mode`, `index <old>..<new> <mode>`, `Binary files differ` for
  binaries, `--- a/x` / `+++ b/x` (`/dev/null` for absent sides), hunks with `@@ -a,b +c,d @@` and
  `\ No newline at end of file`. Files gated `tooLarge` are included (compute their hunks); `huge`
  files emit a `Binary files`-style stub line with a comment. Worktree-layer files use the worktree
  content as the new side. Reuse `hunksFromOps` output; do not reimplement Myers.
- `summarise()`: refs (reuse `loadRefs`), `operation`, index + counts-only worktree scan (no hashing
  beyond the stat check; `hashes: false` option on the scanner if needed), `vsUpstream` for the checked
  out branch via `aheadBehind`, `lastCommit` from HEAD; must not disturb an open diff generation.
- `EngineApi.patchText`, `EngineApi.summarise`.

## Tests
- For `basic`, `renames`, `binary`, `worktree`, `large`: write the patch to a temp copy of the fixture
  and run `git apply --check` (the fixture builder runs git; tests may shell out via `Bun.spawn` in
  `src/engine/**` tests only when `git` is on PATH, skip otherwise with a logged reason); the patch for
  `basic` equals `git diff main feature` byte-for-byte except hunk context differences (assert file
  headers and `numstat` of the applied result instead).
- `summarise` on `worktree` returns the right counts and on `rebase-conflict` the operation.
