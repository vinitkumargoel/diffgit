# T10.7 — Secret and credential scanner

**Size:** M · **Depends on:** T10.6 · Atlas tab 14

## Deliverables
- `src/engine/scan/secretRules.ts` (new): ≈ 60 compiled rules `{ id, description, regex, entropyMin? }`
  covering AWS access keys, AWS secret keys (entropy-gated), GitHub `ghp_/gho_/ghu_/ghs_/ghr_`, GitLab
  `glpat-`, Slack `xox[abp]-`, Stripe `sk_live_`, Google API keys `AIza`, Anthropic `sk-ant-`, OpenAI
  `sk-`(entropy-gated), Twilio, SendGrid, npm `npm_`, PyPI `pypi-`, JWT (three base64url segments,
  entropy-gated), private key headers (RSA/EC/OPENSSH/PGP), generic `password=`/`secret=`/`token=`
  assignments (entropy-gated), connection strings with credentials. Plus `RULESET_DATE`.
- `src/engine/scan/entropy.ts`: Shannon entropy in bits/char.
- `src/engine/scan/secrets.ts`: `scanSecrets(generation)` — for each file in the current diff with
  `staged`/`unstaged` layers and not `generated`/binary/`tooLarge`, take the added lines of its hunks
  (reuse `describeFile`), test rules, skip lines ending in `# diffgit:allow-secret` /
  `// diffgit:allow-secret`, skip paths listed in `.diffgitignore-secrets` (gitignore syntax, repo
  root), skip 40/64-hex-only tokens (sha1/sha256), `masked` = first 8 + `…` + last 4 chars. Return
  findings sorted by path, line; emit `SECRETS_FOUND` warning with the count. `STALE`/`CANCELLED`.
- `EngineApi.scanSecrets`; progress phase `"secrets"`.

## Tests
- `secrets` fixture: exactly the planted keys are found (AWS, GitHub, Anthropic, private key), the
  hex sha is not, the allowlisted line is not; `masked` never contains the middle of the token;
  entropy of a planted random token > 3.8 and of `AAAAAAAA` < 1; a second scan on a clean fixture
  returns `[]` and no warning.

## Acceptance
- [ ] Zero false positives on every other fixture (`bun test` iterates all fixtures); `bun run check` green.
