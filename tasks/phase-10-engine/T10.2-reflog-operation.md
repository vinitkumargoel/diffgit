# T10.2 — Reflog reader and in-progress operation detector

**Size:** M · **Depends on:** T10.1 · Atlas tab 07

## Deliverables
- `src/engine/git/reflog.ts` (new): parse `.git/logs/HEAD` and `.git/logs/<fullRef>` lines
  `old new name <email> ts tz\tmessage`; `action` = text before the first `:` (`commit`, `checkout`,
  `reset`, `rebase (pick)`, `merge`, …); newest first; `limit`; torn-read retry (150 ms) like the index
  reader; missing file → `NO_REFLOG` warning and `[]`. `reachable` is `null` here (T10.5 fills it).
- `src/engine/git/operation.ts` (new): `detectOperation(fs, db)` → `RepoOperation | null` from
  `MERGE_HEAD`, `CHERRY_PICK_HEAD`, `REVERT_HEAD`, `BISECT_LOG`/`BISECT_START`, `rebase-merge/`
  (`msgnum`, `end`, `onto`, `head-name`, `git-rebase-todo`, `done`, `interactive`) and `rebase-apply/`
  (`next`, `last`, `onto`, `head-name`). `conflicts` = number of paths with stage > 0 in the index.
  `remaining`/`done` from the todo files (oids resolved). Unknown layout → `{kind, conflicts}` only.
- `RepoInfo.operation`, `RepoInfo.jj` (`.jj/` exists), `RepoInfo.hasCommitGraph`
  (`.git/objects/info/commit-graph` or `commit-graphs/commit-graph-chain` exists). `reloadRefs()`
  refreshes `operation`. `OPERATION_IN_PROGRESS` warning emitted once per open when non-null.
- `EngineApi.reflog`, `EngineApi.operation`. Polling probe tier `git` must also hash the operation
  files so the banner updates live (extend `probe("git")`).

  conflicts:2}`; clean fixtures `null`; a repo without logs → `NO_REFLOG` warning.
