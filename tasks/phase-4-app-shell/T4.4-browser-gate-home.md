# T4.4 — BrowserGate + HomeScreen

**Phase:** 4 · **Size:** M · **Depends on:** T4.3 · **Blocks:** T5.1, T5.5
**Plan refs:** §6.1 screens 1–3, D3, D4 · **Design refs:** Design.md §3, §4, §5, §7.8

## Goal
First-run and returning-user entry points: unsupported-browser page, open button, recent repos, loading progress.

## Deliverables
- `src/ui/components/BrowserGate.tsx`: renders children only if `"showDirectoryPicker" in window`; otherwise a full-page notice listing Chrome, Edge, Brave, Arc (desktop) and explaining why (File System Access API), with the privacy line "nothing leaves your browser".
- `src/ui/components/HomeScreen.tsx`: logo/name, one-paragraph privacy statement, primary button "Open repository" → `showDirectoryPicker({ mode: "read", id: "diffgit-repo" })` → `upsertRepo` → `store.openRepo`. Handles `AbortError` (user cancelled) silently; other errors → toast.
- `RecentRepoList.tsx`: rows with name, "opened N ago", remove ×; click → `ensurePermission` (inside the click handler) → open; `denied` → inline message with "Try again".
- `LoadingScreen.tsx`: phases from `Progress` (T3.5) with counts ("Scanning working tree 1,240 / 5,000"), cancel button (calls `closeRepo`).
- Route-less: `App.tsx` switches on `store.repo` / `store.loading`.

## Tests
vitest: gate renders notice when API missing; home lists recents from a mocked persistence module; cancel on `AbortError` shows nothing. No separate Playwright test here; the open flow is covered by T7.1 spec 1.

## Acceptance criteria
- [ ] Green; keyboard: `o` opens picker (only when on Home), Enter on a focused recent row opens it.
