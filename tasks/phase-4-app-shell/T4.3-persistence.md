# T4.3 — Persistence: recent repos (IndexedDB) and prefs (localStorage)

**Phase:** 4 · **Size:** M · **Depends on:** T4.2 · **Blocks:** T4.4
**Plan refs:** §5.8, D4, §1 finding 3

## Goal
Recent repos survive reloads with their directory handles; user prefs and viewed marks persist; everything degrades gracefully when storage is unavailable.

## Deliverables
- `src/ui/persistence/repos.ts` (idb-keyval, store name `diffgit-repos`):
  ```ts
  interface StoredRepo { id: string; name: string; handle: FileSystemDirectoryHandle; lastOpenedAt: number; lastSource?: string; lastTarget?: string; }
  listRepos(): Promise<StoredRepo[]>            // newest first, max 20
  upsertRepo(handle): Promise<StoredRepo>       // dedupe with handle.isSameEntry()
  touchRepo(id, patch)                          // lastOpenedAt, lastSource/lastTarget
  removeRepo(id)
  ensurePermission(handle): Promise<"granted" | "denied">   // queryPermission({mode:"read"}) then requestPermission; must be called from a user gesture
  ```
- `src/ui/persistence/viewed.ts`: `idb` map `viewedKey → true`, pruned to 5k entries LRU.
- `src/ui/persistence/prefs.ts`: `localStorage` JSON `{ viewMode, ignoreWhitespace, theme, sidebarWidth, sidebarLayout }` with schema validation and defaults; every read/write wrapped in try/catch (private mode).

## Tests (vitest + `fake-indexeddb`)
upsert dedupes by `isSameEntry` (mock handle), ordering, cap at 20, remove, prefs default on corrupt JSON, storage throwing does not throw out.

## Acceptance criteria
- [ ] Green; manual check in Chrome: reload → recent repo present → click → single permission prompt → opens.

## Amendments (review round 1)
- Storage failures surface as `STORAGE_UNAVAILABLE` (warning-level toast "Recent repos won't be remembered in this browser"), never as a crash.
- E2E markers (T0.4) are stored as-is; `ensurePermission` returns `"granted"` for markers; `isSameEntry` fallback compares `snapshotId`.
- `HANDLE_GONE` from the engine (folder moved/deleted) → remove the recent entry after the user confirms, show the error screen with "Choose folder again".
