# T4.1 — Worker client (typed comlink proxy)

**Phase:** 4 · **Size:** S · **Depends on:** T0.1 (uses a mock until T3.5 lands) · **Blocks:** T4.2
**Plan refs:** §3, §6.3, T3.5 API

## Goal
The UI talks to the engine through one typed module; a mock implementation backed by recorded JSON lets the UI track proceed before the engine exists.

## Deliverables
- `src/ui/workerClient.ts`: `createWorkerClient(): WorkerClient` wrapping `new Worker(new URL("../engine/worker.ts", import.meta.url), { type: "module" })` with comlink. API mirrors `RepoSession` (T3.5) with `onProgress` callbacks wrapped in `Comlink.proxy`.
- `src/ui/workerClient.mock.ts`: same interface, serves `src/test/recorded/*.json` (T3.5 produces these; until then, hand-write `basic.diffresult.json` from Plan §4 shapes with ~6 files covering each status/layer/binary/image/tooLarge). Selected via `import.meta.env.VITE_MOCK_ENGINE === "1"`.
- `src/ui/errors.ts`: `describeError(code): { title, message, action?: "choose-folder" | "retry" | "reopen-permission" }` for every engine code (list from README conventions + task files: `NOT_A_REPO`, `WORKTREE_GITDIR`, `REFTABLE`, `BARE_REPO`, `INDEX_UNSUPPORTED`, `PERMISSION`, `REF_NOT_FOUND`, `CANCELLED`, `TOO_LARGE`, `EROFS` (should never surface: "internal bug"), `EIO`).

## Acceptance criteria
- [ ] `VITE_MOCK_ENGINE=1 bun run dev` renders using mock data once T4.4/T5.x exist; unit test asserts mock and real clients have identical TypeScript interface (`satisfies WorkerClient`).
- [ ] `describeError` has an entry for every code (test iterates a `KNOWN_CODES` array exported from `src/engine/errors.ts`).

## Amendments (review round 1)
- Interface includes `probe()`, `prioritise(ids)`, `generation`-taking `fileDiff/fileStats/fileBytes`, and the single progress/stats sink registered at `open` (see T3.5 amendments). The mock implements all of them (`probe` returns a counter-based signature that changes when the mock's `mutate()` is called).
- `worker.onerror` / `messageerror` → mark client dead, reject in-flight calls with `WORKER_CRASHED`, recreate the worker, and re-open with the retained `handle` + last `DiffSource` (the client keeps both). Store shows "Engine restarted, refreshing".
- `describeError` covers exactly `PUBLIC_CODES` from `src/engine/errors.ts`; test iterates that array.
