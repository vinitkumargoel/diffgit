# T6.4 — Force refresh (re-hash everything)

**Phase:** 6 · **Size:** S · **Depends on:** T6.1 · **Blocks:** T7.1
**Plan refs:** §11 R1

## Deliverables
- Refresh button click = `request("manual")`; **Shift+click** or long-press, and `Shift+R` = `request("force")` which calls `forceRehash()` (clears the stat cache so every index entry is re-hashed) and `invalidate("all")`.
- Tooltip explains: "Force refresh re-reads every file (use if a change isn't showing)".
- Progress in the refresh control while a force refresh runs (uses `Progress` phases).

## Tests
vitest: Shift+click dispatches `force`; scheduler test for `force` path calls `forceRehash` before compute.

## Acceptance criteria
- [ ] Green; manual: same-size same-millisecond edit (scripted `touch -r`) is picked up only by force refresh, confirming R1 behaviour is documented and handled.
