## Deliverables
- `src/ui/refresh/observer.ts`: `startObserver(handle, scheduler): () => void` (returns stop). Feature-detect `"FileSystemObserver" in window`; on absence return `null` so T6.3 polling takes over; on `errored`/`disappeared` records stop and downgrade to polling with a toast "Live updates stopped; polling".
- Classifier (`classifyPaths(records) → { git: boolean; worktree: string[]; ignore: boolean }`), initial rules (replace with S3 findings):
  - `.git/HEAD`, `.git/index`, `.git/packed-refs`, `.git/refs/**`, `.git/ORIG_HEAD`, `.git/MERGE_HEAD`, `.git/logs/HEAD` → `git`.
  - `.git/index.lock`, `*.lock` under `.git` → ignore (wait for the rename).
  - `.git/objects/**` → ignore.
  - anything else under `.git/` → ignore.
  - outside `.git`: ignore paths that `IgnoreRules` marks ignored? (The UI has no ignore rules; send the paths to the scheduler as `worktree` and let the engine's stat cache make no-op recomputes cheap.) Editor temp files (`.swp`, `~`, `.tmp`, `4913`) → ignore list.
- Debounce per S3 recommendation (default 300 ms; `gc` bursts must collapse to ≤ 1 recompute).
