# T5.5 — Empty / error / loading / warning states

**Phase:** 5 · **Size:** S · **Depends on:** T5.1, T5.2 · **Blocks:** T5.6
**Plan refs:** §6.1 screens 5–6, banner area, D7, error codes (T4.1) · **Design refs:** Design.md §3.4, §7.3, §7.8

## Deliverables
- `EmptyState.tsx`: "No changes between `feature` and `main`" + "Working tree is clean" line when the worktree layer applied; secondary action "Change target".
- `ErrorScreen.tsx`: uses `describeError` (T4.1); actions: choose another folder / retry / re-grant permission.
- `WarningBanners.tsx`: one dismissible row per warning code with copy:
  - `UNRELATED_HISTORIES` "Branches share no history; showing a direct comparison."
  - `WORKTREE_NOT_APPLICABLE` (info) "Uncommitted changes are only shown when the source is the checked-out branch."
  - `SPLIT_INDEX` (error-level) "Split index is not supported; uncommitted changes hidden."
  - `SPARSE_INDEX` "Sparse checkout: untracked file detection is partial."
  - `AUTOCRLF` "core.autocrlf is set; line-ending-only changes may appear."
  - `UNTRACKED_CAPPED`, `RENAME_LIMIT`, `FILE_TOO_LARGE`, `EMBEDDED_REPO`, `MULTI_PACK_INDEX`, `SHALLOW`, `LFS_PRESENT`, `GLOBAL_EXCLUDES_UNAVAILABLE`, `CONFIG_INCLUDE_SKIPPED`, `INDEX_CHECKSUM` ("Index was being written; showing last good read").
- Toasts for transient errors (recompute failed → "Retry").

## Tests
vitest snapshot for each warning code; exhaustive test that every `RepoWarning` code exported from the engine has copy.

## Acceptance criteria
- [ ] Green; no raw error codes visible to users.

## Design amendments (approved direction A, 2026-09-16)
- `WarningBanners` use the three levels in Design §3.4 with the icon / bold subject / message / dismiss layout of §7.3. Level per code: **info** `WORKTREE_NOT_APPLICABLE`; **error** `SPLIT_INDEX`, `INDEX_TOO_LARGE`; everything else **warning**. The registry test asserts every code has both copy and a level.
- `EmptyState` replaces the pane and hides the sidebar; `ErrorScreen` and toasts per Design §7.8 (icons, sizes, `--success` primary action, `--accent` Retry link, 8 s auto-dismiss).
- AC added: banner and empty/error snapshots in both themes; no literal colours in `WarningBanners.tsx`, `EmptyState.tsx`, `ErrorScreen.tsx`, `Toast.tsx`.
