# T5.4 — ImageDiff, BinaryNotice, LargeFileGate, Submodule/Typechange notices

**Phase:** 5 · **Size:** M · **Depends on:** T5.3 · **Blocks:** T5.5
**Plan refs:** §6.1, §6.7, T3.4 classification · **Design refs:** Design.md §7.7

## Deliverables
- `ImageDiff.tsx`: side-by-side old/new (`fileBytes(id, side)` → `Blob` → `URL.createObjectURL`), dimensions + byte size under each, checkerboard background, "Added"/"Deleted" single-pane variants; SVG rendered as `<img>` (never inline) for safety; URLs revoked on unmount.
- `BinaryNotice.tsx`: "Binary file not shown" with sizes and a "view as text" escape hatch only if < 1 MB.
- `LargeFileGate.tsx`: for `tooLarge`: "Large diff (3,412 lines changed). [Load diff]"; for > 10 MB: "Diff too large to display" with sizes.
- `SubmoduleNotice.tsx`: "Subproject commit abc123 → def456".
- `TypechangeNotice.tsx` above the diff body when type changed (e.g. "Symlink → regular file").

## Tests
vitest for each notice with recorded classification data; image URL revoke called on unmount (spy).
