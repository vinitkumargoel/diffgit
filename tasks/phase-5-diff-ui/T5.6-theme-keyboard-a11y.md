# T5.6 — Theme, keyboard shortcuts, help dialog, accessibility

**Phase:** 5 · **Size:** M · **Depends on:** T5.1–T5.5 · **Blocks:** T7.1
**Plan refs:** §6.4, §6.5, §6.6 · **Design refs:** Design.md §3 (all tokens), §5, §8, §9, §11

## Deliverables
- Theme: `prefers-color-scheme` default + manual toggle persisted; all colours via CSS variables; diff colours per §6.4; verify contrast ≥ 4.5:1 for text on add/del backgrounds.
- Shortcuts (`useShortcuts` hook, ignores when typing in inputs): `o` open, `r` refresh, `j/k` next/prev file, `v` toggle viewed, `[`/`]` collapse/expand active file, `/` focus filter, `s` split/unified, `?` help, `Esc` close popovers.
- `HelpDialog.tsx` listing shortcuts and the privacy model.
- A11y: line numbers and change type exposed as accessible text where the chosen renderer allows (`aria-label` on gutter cells or visually-hidden text); `aria-label` on status icons and chips; focus rings; `aria-live="polite"` region announcing "Diff updated: n files" on recompute; skip-link to main; roving tabindex in sidebar rows.
- Run `axe` (via `@axe-core/playwright`) on Home, Repo, Empty, Error screens.

## Acceptance criteria
- [ ] axe reports zero serious/critical issues (vitest-axe on Home/Empty/Error components; browser axe on the repo screen lives in T7.1) — this replaces any table-structure requirement, which the candidate renderers cannot meet.
- [ ] All shortcuts covered by vitest hook tests.
