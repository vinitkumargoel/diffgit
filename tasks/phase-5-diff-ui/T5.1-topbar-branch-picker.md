# T5.1 — TopBar + BranchPicker

**Phase:** 5 · **Size:** M · **Depends on:** T4.2, T4.4 · **Blocks:** T5.5
**Plan refs:** §6.1 screen 4 (top bar), D5, D6, D8, D9 · **Design refs:** Design.md §3.3 (badges), §7.1, §7.2, §8

## Goal
The control strip: repo name, source → target pickers, swap, include-uncommitted toggle, refresh control, view controls, filter.

## Deliverables
- `TopBar.tsx` layout (wraps on narrow widths; min 1024 px optimised). Pickers are labelled GitHub-style **`base: [target ▾] ← compare: [source ▾]`**; the engine still calls them target/source. Tooltip on the arrow: "Shows what compare adds on top of base".
- `BranchPicker.tsx` using `cmdk`: trigger shows branch name + badges (`HEAD`, `default`, `remote` chip); popover with search, groups "Local" / "Remote: origin" / other remotes; keyboard: type-to-filter, ↑↓, Enter, Esc; highlights the current selection; sorted per T1.4.
- `SwapButton.tsx` (`⇄`), disabled when source === target.
- `IncludeWorktreeToggle.tsx`: checked by default; disabled with tooltip "Only available when the source is the checked-out branch (X)" when `!canIncludeWorktree`.
- `RefreshControl.tsx`: button + status dot: green "Live" (observer), amber "Polling", grey "Manual"; tooltip "Last refreshed 12 s ago"; spinner while `refresh.busy`. Wire to `store.recompute("manual")` (T6.x supplies the modes; until then, show Manual).
- `ViewControls.tsx`: Unified | Split segmented control; whitespace toggle (icon with tooltip "Ignore whitespace"); theme toggle.
- `FileFilter.tsx`: input with `/` shortcut focus, clear button, shows "n of m files".
- `ViewedCounter.tsx`: "3 / 12 viewed" with a progress bar (GitHub style).

## Tests (vitest)
Picker defaults & grouping from recorded `RepoInfo`; choosing a target calls `setTarget`; toggle disabled state logic; swap disabled when equal.

## Acceptance criteria
- [ ] Green; all controls keyboard-operable; no layout shift when the branch name changes (fixed min-width trigger).

## Amendments (review round 1)
- The picker lists the synthetic `HEAD (detached @ sha)` / `HEAD (no commits)` entry from T1.4 when present, pinned first; selecting it sets `sourceRef = "HEAD"`.
- Selections set `sourceRef`/`targetRef` (full names); display names may collide (`origin/main` vs a local branch literally named `origin/main`) — show the `remote` chip to disambiguate.

- The top bar is **two rows** (44 px + 40 px) with the exact control order of Design §7.1 (row 1: repo, base/compare pickers, swap, divider, include-uncommitted, spacer, refresh, theme) and §7.2 (row 2: summary, viewed counter, spacer, filter, Unified|Split, whitespace). Do not collapse to one row or move controls elsewhere.
- `BranchPicker` trigger and popover sizes, badge colours and group headers per Design §7.1; badges reuse `Badge` from T5.2.
- Refresh dot colours and words: Live `--success`, Polling `--attention`, Manual `--muted` (Design §7.1 item 7).
- Segmented control and whitespace pressed state per Design §8 ("Active/pressed segment").
