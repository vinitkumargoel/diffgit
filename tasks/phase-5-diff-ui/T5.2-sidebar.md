# T5.2 — Sidebar: file tree / flat list

**Phase:** 5 · **Size:** M · **Depends on:** T4.2 · **Blocks:** T5.5
**Plan refs:** §6.1 (left sidebar), §6.7 (>1000 files) · **Design refs:** Design.md §3.3, §6, §7.4, §8

## Goal
GitHub-like file navigator with status, stats, layer chips, viewed state, keyboard navigation, and virtualisation.

## Deliverables
- `Sidebar.tsx`: resizable (drag handle, width persisted via prefs), header with "Files changed (n)" and tree/flat toggle.
- `FileTree.tsx`: folders collapsible (collapsed state in component memory), compact single-child folder chains (`src/ui/components` shown as one row like GitHub).
- `FileRow.tsx`: status icon (A green, M amber, D red, R blue with `old → new` tooltip, T for typechange), path (dir dimmed, basename bold, middle-ellipsis on overflow), `+n −m` (or skeleton while stats load; `—` for binary), layer chips (`staged`, `unstaged`, `untracked`, `conflict`; committed shows none), viewed check (dimmed row when viewed), active row highlight.
- Virtualise with `@tanstack/react-virtual` when rows > 300 (tree flattened to visible rows).
- Click → `setActiveFile` + scroll DiffPane to the card; `j`/`k` move active; `v` toggles viewed on the active file.
- Stats loading: on diff ready, request `fileStats` in batches of 20 in visible order (sidebar order), abort on recompute.

## Tests (vitest)
Tree model compaction, ordering equals engine order, chips per layer, virtualised path renders only visible rows (mock `getBoundingClientRect`).

## Acceptance criteria
- [ ] Green; 5,000-row recorded list scrolls without dropped frames in manual check (note in CHANGELOG).

## Amendments (review round 1)
- Stats are pushed by the worker (`onStats`, T3.5); the sidebar only calls `store.prioritise(visibleIds)` on viewport change (debounced 100 ms). Remove the UI-side batching bullet.
- Files with `generated = true` (T3.4) show a `generated` chip.

## Design amendments (approved direction A, 2026-09-16)
- Sidebar default width 300 px, resizable 220–480 px, 36 px header with `Tree | Flat` mini segmented control (Design §7.4). Tree is the default mode.
- `FileRow` is 26 px with the exact element order in Design §7.4; active row = `--accent-subtle` + 2 px inset `--accent` bar; hover `--surface-raised`; viewed rows at 55 % opacity.
- **Create the shared primitives here**: `StatusIcon.tsx` (16 px square, letter, `aria-label`), `LayerChip.tsx` (staged / unstaged / untracked / conflict / generated), `Badge.tsx` (HEAD / default / remote), all coloured from the Design §3.3 pairs via tokens. T5.1 and T5.3 import them.
- Stats skeleton is a 32 × 10 px `--surface-raised` bar; binary shows `—`.
- AC added: `StatusIcon`, `LayerChip`, `Badge` have vitest snapshots in both themes (toggle `.dark` on `document.documentElement`).
