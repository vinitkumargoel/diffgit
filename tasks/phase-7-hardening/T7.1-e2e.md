# T7.1 — End-to-end smoke suite (Playwright, Chromium) — deliberately small

**Phase:** 7 · **Size:** M · **Depends on:** T5.6, T6.2, T6.3, T6.4 · **Blocks:** T7.2–T7.4
**Plan refs:** §9 E2E, §13 checklist, README "E2E policy"

## Goal
Three browser specs that prove the whole pipeline works end to end in a real Chromium with the production CSP. Everything else is covered by `bun test` (engine parity) and vitest (UI logic), which are far cheaper to write and run. Do not add specs beyond these three without a Plan change.

## Specs (`e2e/`), all using `fsaShim` + memory snapshots of fixtures
1. **`open-and-diff.spec.ts`** (`remote` snapshot): home → open → repo screen; source = checked-out branch, target = `origin/main`; file list shows the expected count; the first text file card renders hunks with highlighted tokens; unified → split toggle changes layout; pick a different target → recompute → list changes; pick target = source → empty state. Run `axe` once on the repo screen with a rendered diff (zero serious/critical).
2. **`worktree-and-refresh.spec.ts`** (`worktree` snapshot): chips for staged / unstaged / untracked visible; "include uncommitted" off → chips gone; on again → back; mutate one tracked file through the channel + emit observer record → its `+/-` changes within 2 s without clicking; add an untracked file → appears; viewed checkbox collapses a card and updates the counter; filter narrows the list.
3. **`errors-and-privacy.spec.ts`**: a snapshot without `.git` → error screen with "choose another folder"; reload → recent repo present → reopen works (marker permission path); **zero network requests after initial load** across the whole spec (`page.on("request")` collected, asserted at the end), run under `vite preview` so the production CSP applies.

## Not in E2E (covered elsewhere — do not duplicate)
Renames/binary/images/large gates (vitest on recorded data + engine parity), keyboard shortcuts (vitest hook tests), torn states (engine tests in T2.1/T3.5/T7.3 with `memoryDirHandle`), detached/unborn (engine + store tests), theme, polling tiers (vitest fake timers), perf (T7.2 bun script).

## CI
One GitHub Actions job: build → `vite preview` → `playwright test` (Chromium only, 1 worker, retries 1). Target runtime < 2 min.

## Acceptance criteria
- [ ] Three specs green locally and in CI in < 2 min total.
- [ ] No other `e2e/*.spec.ts` files exist.
