# T0.3 — Fixture builder

**Phase:** 0 · **Size:** M · **Depends on:** T0.1 · **Blocks:** T0.4, all engine tests
**Plan refs:** §9 (testing strategy)

## Goal
Reproducible git repositories, built with the real `git` CLI, plus JSON "expected" outputs from git, so engine tests can assert parity with git.

## Deliverables
- `scripts/make-fixtures.sh` (bash, `set -euo pipefail`, idempotent: deletes and rebuilds `fixtures/`). Uses `GIT_AUTHOR_DATE`/`GIT_COMMITTER_DATE` fixed values and `-c user.name=test -c user.email=test@example.com` so oids are deterministic.
- `scripts/fixture-expectations.sh`: for each fixture writes `fixtures/<name>/expected/*.json` (use `jq` if available; otherwise emit line-based `.txt` and convert in the test loader).
- `fixtures/README.md` describing each fixture and its branches.
- `src/test/fixtures.ts`: `fixturePath(name)`, `loadExpected(name, file)`, and a guard that fails tests with a clear message if `fixtures/` is missing ("run bun run fixtures").
- `package.json` script `fixtures`: runs both scripts.

## Fixtures to build (names are contract; later tasks reference them)
| Name | Contents |
|------|----------|
| `basic` | `main` with 3 commits; branch `feature` diverges 2 commits; `main` has 1 extra commit after divergence (so two-dot ≠ three-dot). Text files modified/added/deleted on `feature`. |
| `renames` | On `feature`: exact rename (`git mv`), 60%-similar rename (edit ~30% lines then mv), a below-threshold rename (rewrite >60%), an added+deleted pair with identical content in different dirs. |
| `binary` | PNG modified, PNG added, `.bin` with NUL bytes modified, SVG modified, a text file that later gains a NUL byte. |
| `worktree` | Checked out on `feature` with: staged modification, unstaged modification, file both staged and further modified, staged new file, untracked file, untracked file in new dir, deleted-unstaged file, deleted-staged file, mode change `chmod +x`, a file changed on `feature` then reverted in worktree to the merge-base content. |
| `conflict` | Mid-merge with a conflicted file (stages 1/2/3 in index). Built with `git merge` that fails; leave the state. |
| `packed` | `basic` then `git gc --aggressive` and `git pack-refs --all` so all refs are packed and objects in a packfile with deltas. |
| `remote` | Clone of `basic` from a local bare repo so `refs/remotes/origin/HEAD` exists and points at `main`; add local branch `topic`. |
| `remote-master` | Same but default branch named `master`, no `main`. |
| `no-origin-head` | Clone then `git remote set-head origin -d`; local has `main` and `master` both (main must win per D8). |
| `index-v4` | `basic` with `git update-index --index-version 4` on a worktree with staged changes. |
| `index-v3` | Same with `--index-version 3` plus an `intent-to-add` file (`git add -N`) to force extended flags. |
| `ignore` | Nested `.gitignore`s: root ignores `build/` and `*.log`; `src/.gitignore` has `!keep.log`; `.git/info/exclude` ignores `secret.txt`; a `node_modules/` dir with 200 files that must be pruned, not walked; ignored dir containing a tracked file. |
| `detached` | HEAD detached at a commit. |
| `unborn` | `git init` with staged file, no commits. |
| `unrelated` | Two branches with no common ancestor (`git checkout --orphan`). |
| `crlf` | File with CRLF endings committed; `core.autocrlf=true` set in config. |
| `large` | One file with 3000 changed lines; one 1.5 MB text file modified; one 11 MB file added (generated, deterministic). |
| `embedded` | A nested repo (`inner/.git`) inside the worktree, untracked. |
| `symlink` | A symlink committed (mode 120000) and its target changed on `feature`. |
| `worktree-gitdir` | A `git worktree add` checkout so `.git` is a file with `gitdir:`. |
| `perf-5k` | 5,000 tracked files across 200 dirs, 3 branches, packed. Built only when `FIXTURES_PERF=1`. |

## Expected outputs per fixture (where applicable)
- `merge-base.json`: `{ "feature": "<oid>" }` (vs default branch).
- `name-status-3dot.json`: parsed `git diff -M --name-status <base>...feature` → `[ {status, oldPath, newPath, similarity} ]`.
- `name-status-3dot-no-renames.json`: same with `--no-renames`.
- `numstat.json`: parsed `git diff --numstat <base>...feature` (binary = `-`).
- `status-porcelain-v2.json`: parsed `git status --porcelain=v2 --untracked-files=all`.
- `refs.json`: `git for-each-ref --format='%(refname) %(objectname)'` + `git symbolic-ref HEAD` + `git symbolic-ref refs/remotes/origin/HEAD || null`.
- `ls-tree.json`: `git ls-tree -r <oid>` for merge-base and tips.
- `check-ignore.json`: `git check-ignore -v --no-index` results for a fixed probe list (`ignore` fixture). `--no-index` is required so tracked-but-ignored paths report the rule; the probe list must exclude `.DS_Store`/`Thumbs.db` (built-in defaults in T2.3 are outside parity).
- `hash-object.json`: `git hash-object` for 5 sample files (used by T2.2).

## Acceptance criteria
- [ ] `bun run fixtures` completes in < 60 s (excluding perf-5k) on macOS with git 2.50.
- [ ] Running it twice yields identical oids (determinism check in the script: compare `git rev-parse feature` before/after).
- [ ] `fixtures/` is git-ignored; CI job (`.github/workflows/ci.yml` stub) runs it before tests.
- [ ] Every fixture listed above exists with the described state (`fixtures/README.md` documents verification commands).

## Notes
- Use `git -c core.autocrlf=false` everywhere except the `crlf` fixture.
- `conflict` fixture must be built last in its own function and never touched by `gc`.
