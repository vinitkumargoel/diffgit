# T0.2 — Cloudflare Pages pipeline

**Phase:** 0 · **Size:** S · **Depends on:** T0.1 · **Blocks:** T8.2
**Plan refs:** §7, §10, D2, D15

## Goal
The hello-world build is live at https://diffgit.com with the production CSP headers, deployable with one command.

## Deliverables
- `wrangler.toml`: `name = "diffgit"`, `pages_build_output_dir = "dist"`, `compatibility_date` = today.
- `public/_headers`:
  ```
  /*
    Content-Security-Policy: default-src 'self'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' blob: data:; font-src 'self'; connect-src 'none'; worker-src 'self' blob:; frame-ancestors 'none'; base-uri 'none'; form-action 'none'
    X-Content-Type-Options: nosniff
    Referrer-Policy: no-referrer
    Permissions-Policy: camera=(), microphone=(), geolocation=()
    Cross-Origin-Opener-Policy: same-origin
  ```
- `public/_redirects`: `/* /index.html 200`.
- `package.json` script `deploy`: `bun run build && bunx wrangler pages deploy dist --project-name diffgit`.
- `docs/deploy.md`: the owner-run steps below and how to roll back (Pages → Deployments → Rollback).

## Steps
1. Owner runs `bunx wrangler login` (interactive; cannot be automated).
2. `bunx wrangler pages project create diffgit --production-branch main`.
3. `bun run deploy`; note the `*.pages.dev` URL.
4. Attach custom domain: `bunx wrangler pages domain add diffgit.com --project-name diffgit` (or Pages → Custom domains). The zone `diffgit.com` is on Cloudflare, so the CNAME is created automatically.
5. Verify headers with `curl -sI https://diffgit.com | grep -i content-security`.

## Acceptance criteria
- [ ] https://diffgit.com serves the placeholder over HTTPS.
- [ ] CSP header present and identical to the file above.
- [ ] Deep link `https://diffgit.com/anything` returns the SPA (200, not 404).
- [ ] `docs/deploy.md` written.

## Notes
- `connect-src 'none'` will break Vite dev HMR websockets only if applied in dev — `_headers` applies to Pages only, so dev is unaffected.
- If Shiki needs `wasm-unsafe-eval` it is already allowed; do not loosen `script-src` further.

## Amendments (review round 1)
- **Cloudflare edge injection**: in the zone/Pages settings disable Web Analytics (auto-inject), Rocket Loader, Email Address Obfuscation, Auto Minify, Mirage/Polish, and any "Zaraz" tag — each injects third-party script and breaks D15/CSP. Document in `docs/deploy.md`.
- AC added: `curl -s https://diffgit.com | grep -Ei 'beacon|rocket-loader|cloudflareinsights|zaraz'` returns nothing (assertion script `scripts/check-prod.sh`, reused by T7.4 and T8.2).
