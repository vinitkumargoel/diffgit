# T0.1 — Repo & toolchain

**Phase:** 0 · **Size:** S · **Depends on:** — · **Blocks:** everything
**Plan refs:** §7 (stack), §8 (layout), D14

## Goal
A buildable, lintable, testable React 19 + Vite + TypeScript + Tailwind v4 skeleton managed by Bun, with the `src/engine` / `src/ui` split in place.

## Deliverables
- `git init` in the project folder, `.gitignore` (node_modules, dist, fixtures/, .wrangler, playwright-report, test-results).
- `package.json` scripts: `dev`, `build`, `preview`, `check` (typecheck + lint + test), `test` (`bun test src/engine`), `test:ui` (vitest), `lint`, `format`.
- `vite.config.ts` with React plugin, Tailwind v4 plugin, worker support (`worker.format = "es"`), `build.target = "es2022"`.
- Solution-style TypeScript: root `tsconfig.json` holds only `references` to `tsconfig.ui.json` (lib `ES2022, DOM, DOM.Iterable`; includes `src/ui`, `src/main.tsx`, `src/App.tsx`, `e2e`) and `tsconfig.engine.json` (lib `ES2022, WebWorker` only; includes `src/engine`). Never put `DOM` and `WebWorker` in one config: they declare conflicting globals. `bun run check` runs `tsc -b`.
- `biome.json` (recommended rules, 2-space, double quotes).
- `src/main.tsx`, `src/App.tsx` ("diffgit" placeholder), `src/index.css` (Tailwind import), `index.html`.
- `src/engine/types.ts` copied verbatim from Plan §4 (this is the shared contract; later tasks extend it, never fork it).
- `docs/CHANGELOG.md` with a "Follow-ups" section.

## Steps
1. `bun init`-style setup; install exact versions and pin them (no `^`).
2. Add the two tsconfigs and make `bun run check` run both typechecks.
3. Verify `bun run build` emits `dist/index.html` and the worker chunk config works with an empty `src/engine/worker.ts` exposing nothing.

## Acceptance criteria
- [ ] `bun run dev` serves the placeholder; `bun run build` produces `dist/`.
- [ ] `bun run check` passes and fails when a `document` reference is added to `src/engine/types.ts` (proves the engine tsconfig guard).
- [ ] Exact versions recorded in `package.json`; `docs/CHANGELOG.md` lists them.

## Notes
- Tailwind v4 uses `@import "tailwindcss";` and the `@tailwindcss/vite` plugin; no `tailwind.config.js`.
- Do not add UI libraries yet (cmdk, virtual, lucide) — Phase 5 adds them.
