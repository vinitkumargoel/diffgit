# T1.2 — Layout checks (unsupported repo shapes)

**Phase:** 1 · **Size:** S · **Depends on:** T1.1, T1.5 · **Blocks:** T3.5
**Plan refs:** §5.2, §4 (`RepoInfo.capabilities`), §1 findings 1–2

## Goal
Before any git operation, classify the folder and either refuse with a precise error or proceed with recorded warnings.

## Deliverables
- `src/engine/git/layoutChecks.ts`: `checkLayout(fs): Promise<LayoutReport>` where
  ```ts
  interface LayoutReport {
    ok: boolean;
    fatal?: { code: "NOT_A_REPO" | "WORKTREE_GITDIR" | "REFTABLE" | "BARE_REPO"; message: string; hint: string };
    capabilities: RepoInfo["capabilities"];
    warnings: RepoWarning[];   // { code, message }
  }
  ```
- Extend `types.ts` with `RepoWarning` codes used here: `MULTI_PACK_INDEX`, `SHALLOW`, `LFS_PRESENT`, `AUTOCRLF`.

## Checks
| Condition | Result |
|-----------|--------|
| no `.git` entry | fatal `NOT_A_REPO`, hint "Choose the folder that contains .git" |
| `.git` is a file starting with `gitdir:` | fatal `WORKTREE_GITDIR`, hint "Open the main repository folder" |
| `.git/HEAD` missing but `HEAD` + `objects` at root | fatal `BARE_REPO` |
| `.git/reftable/` exists or `.git/refs/heads` missing and `refs/` contains `refs/tables.list` | fatal `REFTABLE` |
| `.git/objects/pack/multi-pack-index` | warning `MULTI_PACK_INDEX` (verify in T1.6 that reads still work) |
| `.git/shallow` | warning `SHALLOW` ("merge-base may be missing") |
| `.gitattributes` mentions `filter=lfs` | warning `LFS_PRESENT` |
| index extensions (filled in by T2.1 later; leave fields default here) | — |

## Tests
Fixtures: `basic` (ok), `worktree-gitdir` (fatal), a temp dir without `.git` (fatal), `packed` (ok). Build a synthetic `reftable` case with `memoryDirHandle`.

## Acceptance criteria
- [ ] Each row above has a test.
- [ ] Function never throws for I/O reasons other than permission (`EACCES` → rethrow as `PERMISSION`).

## Amendments (review round 1)
Additional checks (each one file read; all turn silent garbage into a precise error):
| Condition | Result |
|-----------|--------|
| config `extensions.objectFormat = sha256` | fatal `OBJECT_FORMAT_SHA256` |
| `.git/objects/info/alternates` exists | fatal `ALTERNATES` ("objects live outside this folder") |
| config `extensions.partialClone` or any `remote.*.promisor` / `.git/objects/pack/*.promisor` | fatal `PARTIAL_CLONE` |
| config `extensions.refStorage = reftable` (in addition to the directory check) | fatal `REFTABLE` |
| sum of `.git/objects/pack/*.pack` sizes > 300 MB | warning `PACK_LARGE` (memory) |
| sum > 1 GB | fatal `PACK_TOO_LARGE` (isomorphic-git loads whole packs; do not attempt) |
`checkLayout(fs, config)` now takes the parsed config (T1.5). Tests: `sha256`, `alternates`, `partial` fixtures refused; synthetic pack-size cases with `memoryDirHandle`.
