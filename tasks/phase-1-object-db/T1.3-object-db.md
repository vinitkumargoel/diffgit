# T1.3 — ObjectDb: isomorphic-git wrapper with session cache

**Phase:** 1 · **Size:** M · **Depends on:** T1.1 · **Blocks:** T1.4, T2.4, T3.1
**Plan refs:** §5.2, §1 finding 1–2

## Goal
All object/ref reads go through one class with a shared isomorphic-git `cache` object and memoised flattened trees. Nothing in this class may call an isomorphic-git function that writes.

## Deliverables
- `src/engine/git/objectDb.ts`:
  ```ts
  class ObjectDb {
    constructor(fs: FsaFs)
    resolveRef(ref: string): Promise<Oid>                                  // always an oid; throws REF_NOT_FOUND
    readSymref(ref: string): Promise<string | null>                       // raw read of the loose ref file; returns target ref if it starts with "ref: ", else null
    tryResolveRef(ref: string): Promise<Oid | null>
    listLocalBranches(): Promise<string[]>
    listRemoteBranches(remote: string): Promise<string[]>
    readCommit(oid): Promise<{ oid, tree: Oid, parents: Oid[], message: string }>
    readBlob(oid): Promise<Uint8Array>
    findMergeBase(a: Oid, b: Oid): Promise<{ oid: Oid | null; all: Oid[] }>   // oid = null when unrelated; all.length > 1 = criss-cross
    flattenTree(commitOrTreeOid: Oid): Promise<FlatTree>     // Record<path, {oid, mode}>; memoised per oid
    dropCaches(): void                                       // called on refresh when refs changed (keeps pack cache)
  }
  type FlatTree = Record<string, { oid: Oid; mode: number }>;
  ```
- `flattenTree` implemented with `git.walk({ trees: [TREE({ref: oid})] })` **with no STAGE/WORKDIR walkers** (pure read), or by recursive `readTree` — pick whichever is faster on `fixtures/perf-5k` and note the measurement.
- Allowed isomorphic-git calls: `resolveRef`, `listBranches`, `readCommit`, `readTree`, `readBlob`, `findMergeBase`, `walk`(TREE only), `listRemotes`. Anything else needs a Plan change.

## Tests (parity against fixture expectations)
- `resolveRef("HEAD")`, branch refs, `refs/remotes/origin/HEAD` symbolic depth-1 resolution on `remote` fixture.
- `findMergeBase` == `merge-base.json` for `basic`, `packed`, `remote`; `null` for `unrelated`.
- `flattenTree(oid)` == `ls-tree.json` (paths, oids, modes incl. `120000` symlink and `100755`).
- `readBlob` bytes equal to file content on disk for a sample.
- All of the above pass on `packed` (delta-compressed pack).
- Write-guard: run the suite with an `FsaFs` spy; assert zero write attempts.

## Amendments (review round 1)
- `resolveRef` with isomorphic-git's `depth` returns a **ref name**, not an oid, and `packed-refs` never contains symrefs — `origin/HEAD` is always the loose file `.git/refs/remotes/origin/HEAD`. Hence `readSymref()` above; T1.4 uses it.
- `findMergeBase`: isomorphic-git returns an array. Return all; the chosen `oid` is `all[0]`. Compare against `merge-base-all.json` on `crisscross`; if git's single `merge-base` pick differs from `all[0]`, document and keep `all[0]` (T3.2 emits `MULTIPLE_MERGE_BASES` so the user knows). Missing objects (shallow clone) must return `{ oid: null, all: [] }` — do not throw; T3.2 adds the `SHALLOW` warning. Test on a synthetic shallow copy (`git clone --depth 1` of the local bare `basic`).
- **Stale pack after `git gc`**: wrap every object read; on `ENOENT` for a `.pack`/`.idx` path, call `dropCaches()` (including the isomorphic-git `cache` object), retry once, and surface warning `STALE_PACK_RETRIED`. Test by swapping the pack file between two reads using `memoryDirHandle`.
- Tests added: `readSymref("refs/remotes/origin/HEAD")` on `remote` = `refs/remotes/origin/main`; `null` on `no-origin-head`.
