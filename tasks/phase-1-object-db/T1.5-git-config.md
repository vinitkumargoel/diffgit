# T1.5 — Minimal `.git/config` parser

**Phase:** 1 · **Size:** S · **Depends on:** T1.1 · **Blocks:** T1.4, T2.4
**Plan refs:** §5.3, §5.5 (autocrlf), §5.6 (renameLimit)

## Goal
Read the handful of config keys the engine needs without pulling a full INI library.

## Deliverables
- `src/engine/git/config.ts`: `parseGitConfig(text): GitConfig` and `loadGitConfig(fs): Promise<GitConfig>`.
  ```ts
  interface GitConfig {
    remotes: string[];                       // [remote "x"] sections
    remoteUrls: Record<string, string>;
    core: { autocrlf?: "true" | "false" | "input"; excludesFile?: string; ignoreCase?: boolean; symlinks?: boolean };
    diff: { renameLimit?: number; renames?: boolean };
    raw: Record<string, Record<string, string>>;   // "section.subsection" -> key -> last value
  }
  ```
- Handles: `[section]`, `[section "sub"]`, `key = value`, `#`/`;` comments, quoted values with `\"` escapes, multi-line `\` continuation, case-insensitive section/key names, `include`/`includeIf` **ignored** (cannot read outside the repo) with a warning code `CONFIG_INCLUDE_SKIPPED`.

## Tests
Hand-written config strings for every syntax rule; `crlf` fixture returns `autocrlf: "true"`; `remote` fixture returns `remotes: ["origin"]`.

## Acceptance criteria
- [ ] Tests green; parser is < 150 lines.
