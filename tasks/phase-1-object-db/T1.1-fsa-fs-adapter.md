# T1.1 — FsaFs: read-only fs adapter for isomorphic-git

**Phase:** 1 · **Size:** M · **Depends on:** T0.4 · **Blocks:** T1.2, T1.3, T1.5, T2.1, T2.3
**Plan refs:** §5.1, §10, D16, §1 finding 1

## Goal
An object satisfying isomorphic-git's `fs.promises` contract, backed by `DirHandleLike`, that can read anything and **cannot write anything**.

## Deliverables
- `src/engine/fs/fsaFs.ts` exporting `createFsaFs(root: DirHandleLike): { promises: FsPromises }`.
- `src/engine/errors.ts`: `EngineError` base (`code`, `message`, `cause?`), plus `fsError(code, path)` helper producing Node-shaped errors (`code`, `errno`, `path`, `syscall`).

## Contract to implement (`promises`)
| Method | Behaviour |
|--------|-----------|
| `readFile(path, opts?)` | `Uint8Array`; if `opts === "utf8"` or `opts.encoding === "utf8"` return string. Missing → `ENOENT`. Directory → `EISDIR`. |
| `readdir(path)` | names array (files + dirs), no `.`/`..`. Not a dir → `ENOTDIR`. |
| `stat(path)` / `lstat(path)` | `{ type, mode, size, mtimeMs, ctimeMs: 0, ino: 0, dev: 0, uid: 0, gid: 0, isFile(), isDirectory(), isSymbolicLink(): false }`. mode `0o100644` for files, `0o40000` for dirs. |
| `readlink` | throws `EINVAL` (FSA cannot see symlinks). |
| `writeFile`, `unlink`, `mkdir`, `rmdir`, `symlink`, `chmod`, `rename` | throw `EROFS` **always**, before any I/O. |

## Path resolution
- Normalise: strip leading `/`, `./`; reject `..` segments with `EINVAL`; `""` and `.` = root.
- `resolve(path): Promise<HandleLike>` walking segments via `getDirectoryHandle` / `getFileHandle` (try dir first for intermediate segments, both for the last segment).
- Cache `Map<path, HandleLike>` for resolved handles; `invalidate()` clears it (called by refresh in T6.1). Cap at 20k entries (drop all when exceeded).
- Map DOM errors: `NotFoundError` → `ENOENT`; `TypeMismatchError` → `ENOTDIR`/`EISDIR` by expectation; `NotAllowedError` → `EACCES`; anything else → rethrow wrapped with `code: "EIO"`.

## Tests (`fsaFs.test.ts`, via `nodeDirHandle` on `fixtures/basic`)
- reads `.git/HEAD` as string and bytes; `readdir(".git/refs/heads")` lists branches.
- error codes for missing file, file-as-dir, dir-as-file, `..` traversal.
- **Invariant test**: every write method throws `EROFS` and the underlying handle received zero calls (use a spy handle wrapper that counts `getFileHandle(name, {create:true})`/`removeEntry` calls — the wrapper should not even expose them).
- cache invalidation: resolve, `invalidate()`, resolve again hits handle again (spy count).

## Amendments (review round 1)
- Use `EngineError`/`fsError` from `src/engine/errors.ts` (T0.1); do not create `errors.ts` here. Map `NotAllowedError` → `EACCES` (fs-tier); the session translates it to `PERMISSION`.
- **Engine-facing API beyond isomorphic-git's contract** (the scanner and ignore walker need it):
  ```ts
  openFile(path): Promise<FileLike>                         // size, lastModified, arrayBuffer(), stream()
  readdirWithKinds(path): Promise<{ name: string; kind: "file" | "directory" }[]>
  getDirHandle(path): Promise<DirHandleLike>
  ```
- **Per-path invalidation**: `invalidatePath(path)` drops that path and its descendants from the handle cache; `invalidateAll()` remains for repo switch/force refresh. Refresh (T6.1) uses per-path invalidation for observer-reported paths and never drops the whole cache on a routine recompute. Any `ENOENT`/`TypeMismatchError` on a cached handle also evicts that path and retries once.
- AC added: cache eviction test; `openFile` returns a `FileLike` whose `stream()` works in Bun and Chrome.
