# T1.4 — RefStore: HEAD, branches, default branch

**Phase:** 1 · **Size:** M · **Depends on:** T1.3, T1.5 · **Blocks:** T3.2, T3.5
**Plan refs:** §5.3, D8, D9, §4 (`RepoRef`, `RepoInfo`)

## Goal
Produce the `refs`, `headBranch`, `headOid`, `defaultRef` fields of `RepoInfo` exactly as the UI needs them.

## Deliverables
- `src/engine/git/refStore.ts`: `loadRefs(db: ObjectDb, config: GitConfig): Promise<RefSnapshot>` with
  ```ts
  interface RefSnapshot { headBranch: string | null; headOid: Oid | null; detached: boolean; unborn: boolean; refs: RepoRef[]; defaultRef: RepoRef | null; }
  ```

## Rules
- HEAD: read `.git/HEAD` raw. `ref: refs/heads/X` → `headBranch = X`; resolve → `headOid`; unresolvable → `unborn = true, headOid = null`. Bare oid → `detached = true, headBranch = null`.
- Branches: local from `listLocalBranches`; remote for every remote in config (`listRemoteBranches(remote)`), skipping the `HEAD` pseudo-entry. `name` for remotes is `"<remote>/<branch>"`.
- Default (D8), first match wins:
  1. `readSymref("refs/remotes/origin/HEAD")` (T1.3) → if it returns `refs/remotes/origin/<x>`, use the remote ref `origin/<x>` if it exists, else local `<x>` if it exists. If the file is absent or not symbolic, fall through to rule 2.
  2. local `main`; 3. local `master`; 4. the checked-out branch; 5. `null` (detached/unborn with no branches).
- Sort: checked-out first, default second, then local A→Z, then remotes grouped by remote name A→Z.
- `isCheckedOut` true only for the local head branch.

## Tests
`refs.json` parity for `basic`, `remote` (default = `origin/main`), `remote-master` (`origin/master`), `no-origin-head` (local `main` beats `master`), `detached`, `unborn`, `packed` (packed refs), plus sort-order snapshot.

- [ ] All fixtures above green.
- [ ] No ref resolution goes around `ObjectDb` (grep: `readFile(".git/refs` not present here; only HEAD is read raw).
